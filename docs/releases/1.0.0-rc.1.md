# CodeRipple 1.0.0-rc.1

This is the first v1.0 release candidate. Use a local tarball to verify
deterministic impact analysis for JavaScript and TypeScript Git revisions.
The package contains the compiled CLI, docs, and a working checkout demo.

## Validate the candidate

1. Install and check the version using the [install guide](../install.md).
2. Compare `demo-base` and `demo-head` using the
   [checkout demo](../../examples/checkout-demo/README.md).
3. Confirm that the report shows the changed shipping rule, callers, one
   static test recommendation, and an unresolved dynamic call.
4. Run the suggested Node test. The test passes while leaving the revised
   threshold boundary uncovered.

To rebuild the artifact, use Node 24.22.0 and pnpm 12.14.0 with
`pnpm install --frozen-lockfile`, then compare two tarballs as shown
in the install guide. From a checkout, run `pnpm typecheck && pnpm lint &&
pnpm test` for the default verification. The optional Neo4j integration suite
requires Docker.

## Compatibility

Use Node.js 22 or later. Git and tar are required for revision analysis and
MCP. Local impact uses `ImpactReport` schema version 1. CodeGraph version 2
is emitted when supported NestJS route metadata is present, and version 1
graphs remain readable. Existing graph indexes can be refreshed using normal
re-indexing. See [known limitations](../limitations.md).

## Release approval

The candidate manifest is private and can be installed locally from the
tarball. Public distribution, including a public prerelease, requires
explicit owner authorization. Before a registry release, the owner confirms
the package name and distribution license, authorizes the manifest change,
and verifies the exact artifact to be published. A GitHub release also
requires owner authorization.
